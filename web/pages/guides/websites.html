How to cite a website or web page in AGLC4

In AGLC4, a web page is cited as: author, ‘title of the page in single quotation marks’, name of the website in italics, then the document type and full date in brackets, any pinpoint, and the URL in angle brackets (r 7.15). For example: ‘Australian Guide to Legal Citation’, Melbourne Law School (Web Page) <https://law.unimelb.edu.au/mulr/aglc>.

The pattern

  • Author. The person or body that wrote the page. Leave the author out when it is the same as the website's name, and when the page doesn't name one.
  • Title of the page. In single quotation marks, roman type.
  • Name of the website. In italics: the site as a whole, such as High Court of Australia or AUSPUBLAW.
  • Document type. What the page is: Web Page, Blog Post, Forum Post or Podcast, for example. If nothing more specific fits, use Web Page.
  • Date. The full date the page was published or last updated, if it shows one. With no date, the brackets hold the document type alone.
  • URL. In angle brackets, at the end. If you have an archived copy, add ", archived at" and its URL in angle brackets after it (r 4.5).

Examples

Where a page does name an author and a date, both go in: the author first, followed by a comma, and the full date after the document type, as in "(Blog Post, 18 October 2017)".

When not to cite something as a web page

Rule 7.15 is for material that has no more specific rule. Many things you find online have their own form, and you should use it:

  • A case on AustLII or a court's site: cite the case, with its report or medium neutral citation, not the web page. See citing cases.
  • An Act on the Federal Register of Legislation or a State site: cite the Act. See citing legislation.
  • A journal article in a database: cite the article. See journal articles.
  • A report published as a PDF: cite the report. See reports.
  • A newspaper's online article: it is a newspaper article, with "(online, date)" in place of the place of publication (r 7.11.2).

Citing the page again

Later references use the author's name, then "(n x)" and any pinpoint. When the page has no author at all, the website's name stands in for it, in italics: AUSPUBLAW (n 5). See subsequent references.

Where the author was left out of the first citation because it is the same as the website's name, {{brand}} still uses that author's name, in roman type, in later references: Australian Human Rights Commission (n 9).

Common questions

Which part of a website citation is italic?

The name of the website as a whole. The title of the page itself goes in single quotation marks.

What if the web page has no date?

Leave the date out, so the brackets hold only the document type: (Web Page).

What if the author and the website are the same?

Leave the author out and start with the page's title, followed by the website's name in italics.

Should I cite a case or an Act I found online as a website?

No. Cite cases, legislation, articles and reports in their own forms, wherever you read them. Rule 7.15 is for web pages that have no more specific rule.

What {{brand}} does

{{brand}} reorders web page citations into the pattern above, italicises the website's name, puts the URL in angle brackets and drops an author that repeats the website's name. It doesn't visit the page, so it can't add a detail you left out: a missing website name is marked [MISSING: website_name], never made up.
