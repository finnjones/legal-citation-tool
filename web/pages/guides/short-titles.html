AGLC4 short titles: how to define and use them

A short title is the name you use for a source once you have cited it in full. You define it in the first footnote, in brackets after the full citation, and use it in every later reference (r 1.4.4).

How to define one

Put the short title in single quotation marks inside round brackets, at the end of the full citation, after any pinpoint. Italicise it for a case, an Act or a report.

Using it later

Later references give the short title, then "(n x)" with the number of the footnote that defined it, then the pinpoint. See subsequent references.

When you don't need one

If you cite a source once, or only repeat it with Ibid, there is nothing to shorten, so don't define a short title. Define it when you will cite the source again in some other way. Books and articles by a named author don't need one either, unless you want one: later references use the author's surname.

What {{brand}} picks

If you have already written a short title in a footnote, {{brand}} keeps it and defines it in the first citation. If you haven't, it adds one only when the source is cited again other than through Ibid. For a case it uses the name of the first party, so Mabo v Queensland [No 2] becomes Mabo. When the first party is the Crown (R, The King or The Queen), it uses the second party instead (r 2.1.14). For an Act or a treaty it uses a short title only if you supplied one.
