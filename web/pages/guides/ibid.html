Ibid in AGLC4: when and how to use it

In AGLC4, use Ibid when a footnote cites the same single source as the footnote immediately before it (r 1.4.3). Write "Ibid" alone if the pinpoint is the same, or "Ibid" followed by the new pinpoint, with no comma, if it differs: Ibid 45. Most mistakes come from using Ibid where it isn't allowed.

When you can use Ibid

  • The footnote just before cites exactly one source, and this footnote cites that same source.
  • Ibid is the first citation in the footnote. A later citation in the same footnote can't use it.
  • No footnote sits between the two, even one with no citation in it. If one does, use a subsequent reference, (n x), instead.
  • This footnote doesn't drop a pinpoint. If the previous footnote had a pinpoint and this one has none, don't use Ibid; use a subsequent reference (r 1.4.1).

How Ibid is written

Ibid starts with a capital at the start of a footnote and is lower case after a signal such as See. When the pinpoint is the same as in the previous footnote, Ibid stands alone. When it differs, the new pinpoint follows Ibid after a space, with no comma and no "at".

Footnote 69 has the same pinpoint as footnote 68, so it is just "ibid", in lower case because the signal See comes first. Footnote 70 has a different page, so the page follows.

Common questions

Is Ibid italicised in AGLC4?

No. Ibid is written in ordinary roman type, with a capital I at the start of a footnote.

Is it Ibid or Ibid., and does it take a comma?

Ibid has no full stop of its own and no comma after it. A footnote that is only Ibid still ends with the footnote's full stop: Ibid. With a new pinpoint, it is Ibid 45.

Can I use Ibid for cases and legislation?

Yes. Ibid works the same way for every kind of source, including cases and Acts: Ibid s 38.

What if the previous footnote cites two sources?

Then you can't use Ibid for either of them. Use a short form with (n x) instead. See subsequent references.
