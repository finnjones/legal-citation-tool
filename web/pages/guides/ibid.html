Ibid in AGLC4: when and how to use it

Ibid tells the reader that a footnote cites the same source as the footnote immediately before it. AGLC4 allows it only in a few situations (r 1.4.3), and most mistakes come from using it where it isn't allowed.

When you can use Ibid

  • The footnote just before cites exactly one source, and this footnote cites that same source.
  • Ibid is the first citation in the footnote. A later citation in the same footnote can't use it.
  • No footnote sits between the two, even one with no citation in it. If one does, use a subsequent reference, (n x), instead.
  • This footnote doesn't drop a pinpoint. If the previous footnote had a pinpoint and this one has none, don't use Ibid; use a subsequent reference (r 1.4.1).

How Ibid is written

Ibid starts with a capital at the start of a footnote and is lower case after a signal such as See. When the pinpoint is the same as in the previous footnote, Ibid stands alone. When it differs, the new pinpoint follows Ibid after a space, with no comma and no "at".
